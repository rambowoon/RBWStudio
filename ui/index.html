        Hướng dẫn Deploy Demo Hosting
        
      

      

        
1
Chuẩn bị thông tin hosting
Nhập IP/Host FTP, tài khoản và mật khẩu DirectAdmin trong Cài đặt chung → Deploy Demo Hosting. Đường dẫn mặc định: /domains/{domain}/public_html.

        
2
Nhấn nút Deploy trên dự án
RBWStudio đọc .env để lấy tên Database local và xuất database.sql bằng mysqldump.

        
3
Tự động tạo Database
Gọi API DirectAdmin tạo Database + User và cập nhật APP_URL, DB_* trong .env.

        
4
Upload & kích hoạt
Tải gói nén qua FTP, giải nén và nạp SQL tức thì qua bridge.php.
